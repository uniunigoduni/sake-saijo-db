# 酒蔵史・銘柄史・おすすめの飲み方 追加調査

確認基準日: 2026-09-06

メインCSVへ追加した `酒蔵の歴史`、`銘柄の歴史`、文章型の `おすすめの飲み方` の根拠をまとめた調査フォルダです。

## 調査方針

歴史は蔵元公式サイトを第一優先とし、公式で確認できない補足だけ酒造組合等の信頼できる二次情報を使用しました。`銘柄の歴史` は商品固有の発売・開発・受賞史が確認できる場合は商品別情報を優先し、確認できない商品はブランド史を示した上で個別発売年を特定できない旨を明記しています。

文章型の `おすすめの飲み方` は、次の順序で根拠を採用しています。

1. 商品ページ等で個別に確認した公式推奨
2. 既存調査で収集済みの飲用温度・飲み方情報
3. 商品の公式出典ページを再走査して検出した飲用表現
4. それでも情報がない場合のみ、分類・生酒/原酒等の製法・日本酒度・アルコール度数から推論

推論した文章は「公開情報で明確な推奨温度を確認できないため酒質からの目安」と本文中に明記しています。
## 収録ファイル

- `brewery_history.csv`: 10蔵すべての酒蔵史と出典URL
- `brand_history.csv`: 18ブランドすべてのブランド史と出典URL
- `product_history_sources.csv`: 商品固有の発売・開発・受賞史を確認できた主要な15ソース
- `sources.csv`: 歴史・ブランド・飲み方調査で参照した中核ソース27件
- `official_serving_scan.csv`: メインCSVの公式商品URLを対象に飲用表現を再走査した記録
- `product_serving_recommendations.csv`: 204商品すべての文章型おすすめ、元の飲み方、根拠区分、出典URL
- `scan_official_serving.py`: 公式商品URLの補助的な飲用表現走査
- `build_history_tables.py`: 酒蔵史・ブランド史・中核ソース表の生成元

## おすすめの飲み方の根拠内訳

204商品すべて入力済みです。最終生成時の内訳は、既存の飲み方情報127件、公式ページ再走査15件、公式・個別確認13件、公開情報が不足したため酒質から推論したもの49件です。

公式URL再走査は175商品URLを対象に実施しました。サイト側のアクセス制限等による取得エラーも `official_serving_scan.csv` の `scan_error` に残しており、取得失敗時に既存の調査値を消したり推測で「公式情報」と扱ったりはしていません。

## 推論時の基本ルール

生酒・生原酒・しぼりたて・発泡/にごりはフレッシュさを優先して冷酒を起点、大吟醸・吟醸は香りを閉じない10〜15℃程度を基本、純米酒は米の旨味が出やすい常温〜ぬる燗も候補としました。ひやおろし・秋あがりは熟成した旨味を見やすい常温〜ぬる燗、お燗酒は商品名の意図を優先します。これは公式推奨ではなく、公開情報がない場合だけ使う補完ルールです。
