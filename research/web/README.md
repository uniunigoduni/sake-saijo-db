# 東広島市・日本酒ネット調査

対象は東広島市内の10蔵。西条酒蔵通り7蔵に、黒瀬の金光酒造、安芸津の今田酒造本店・柄酒造を加える。

## 対象酒蔵
- 西条: 山陽鶴酒造、白牡丹酒造、西條鶴醸造、賀茂鶴酒造、亀齢酒造、福美人酒造、賀茂泉酒造
- 黒瀬: 金光酒造
- 安芸津: 今田酒造本店、柄酒造

## 方針
- 現行・休売・終売・状態不明を問わず、存在確認できた日本酒商品を収集する。
- 推測で項目を補完しない。不明・確認不能は空欄または「不明」とする。
- `index.csv` は普段参照する構造化索引。
- 酒蔵別フォルダの銘柄Markdownは、根拠URL・確認日・販売状態の根拠などを保持する。
- `sources.jsonl` は共通の出典台帳。可能なページは各酒蔵の `evidence` に取得時点の原本を保存する。
- 販売状態は `販売中 / 休売 / 終売 / 不明` の4値に限定する。
- 公式ページ掲載中・公式通販で購入可能など明確な根拠がある場合のみ「販売中」とする。
- 公式に休売・販売休止の記載がある場合のみ「休売」、終売・販売終了・製造終了等の記載がある場合のみ「終売」とする。
- 過去ページや第三者情報で存在だけ確認でき、現在状態が確定できないものは「不明」とする。
- 二次DBの未照合候補は本索引へ直接入れず、`_research_log/secondary_candidates_higashihiroshima.jsonl` に分離する。
